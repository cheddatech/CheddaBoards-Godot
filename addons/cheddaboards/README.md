# CheddaBoards SDK 2.3.0

Online leaderboards, achievements and sign-in for Godot 4.6+.

- Docs: https://docs.cheddaboards.com/quickstart/godot
- Changelog: https://github.com/cheddatech/cheddaboards-godot-addon/blob/main/CHANGELOG.md
- Status: https://status.cheddatech.com

Enable the plugin in Project Settings → Plugins to register the
`CheddaBoards` autoload. `SetupWizard.gd` (File → Run) writes your API
key in. `ui/DeviceCodeLogin.tscn` is a drop-in sign-in popup.
